# LLM 非同期テスト手順

## 1. 基本動作
1. IME を起動し、日本語入力モードで `きょうは` を入力。
2. `Space` で候補ウィンドウを開き、翻訳プレースホルダ `翻訳中` が表示されることを確認。
3. 約 1〜2 秒以内に英訳候補が先頭に差し替わり、選択中のままになることを確認。

## 2. キャッシュ巡回 (Space)
1. 同じ文で `Shift+Space` を押し、新しい翻訳が取得されるまで待機。
2. `Space` を繰り返し押下し、取得済み翻訳が巡回表示されることを確認する（UI の選択が英訳候補間で切り替わる）。
3. プレースホルダ表示中に `Space` を押しても、リクエストの完了待ちであること（巡回しない）を確認。

## 3. 複数キューの同時実行
1. 翻訳中の状態で別の文（例: `おおさかへ`）を入力し直し、新しい候補を開く。
2. 先行リクエストがキャンセルされ、新しいプレースホルダが表示されることを確認。
3. 先行応答が後から到着しても、新しい文の候補を上書きしないことを確認。

## 4. 再利用確認
1. `Esc` で候補を閉じたあと同じ文で候補を再度開く。
2. キャッシュから即時に翻訳候補が復元され、プレースホルダを挟まないことを確認。

## 5. エッジケース
- ネットワーク切断中に `Space → Shift+Space` を押してエラーを発生させ、プレースホルダが消えて既存候補へ戻ることを確認。
- 翻訳結果が空文字の場合（強制的に LLM へ空白を送信）に、候補が追加されないことを確認。
