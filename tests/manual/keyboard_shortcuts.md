# ショートカットの実機確認

最新のRTASを登録し、新しく起動したテスト用エディターで確認する。未保存のユーザー文書は使わない。
既定のEnterは日本語の保持、もう一度Enterで日本語確定、保持中のSpaceで翻訳という操作を維持する。

1. `konnichiha` → `F6`で「こんにちは」、`F7`で「コンニチハ」、`F8`で「ｺﾝﾆﾁﾊ」。
   `F9`で「ｋｏｎｎｉｃｈｉｈａ」、`F10`で「konnichiha」。同じF9/F10の反復で大文字・単語先頭大文字へ変わる。
2. 同じ入力でCtrl+U/I/O/P/T、無変換、Shift+無変換も確認する。変換前の読みが失われないこと。
3. `ka` → Ctrl+Space → `ki`で「か き」。Ctrl+Shift+Spaceでは全角空白になる。
4. 「かきく」を入力しHome、Right、`sa`で「かさきく」。Deleteで直後、Backspaceで直前だけが消える。
   Home/End、Shift+左右、Shift+Home/Endで範囲選択し、文字入力または削除でその範囲だけを変更する。
5. 日本語候補を開き、上下、Tab/Shift+Tab、Space/Shift+Spaceで順／逆送り。
   候補が10件以上ある語でPageUp/PageDownを試し、末尾ページの番号・選択と1〜9（テンキー含む）が一致する。
6. Ctrl+Tabで日本語→言い換え→翻訳、Ctrl+Shift+Tabで逆に戻れる。翻訳のShift+Spaceは再問い合わせ。
   文字種変換や編集の後に、以前の翻訳応答が候補を上書きしないこと。
7. 未確定中もCtrl+C/V/X/Z/Y/A/S、Alt+F4、Shift+F10を文字入力として取り込まないこと。
   Ctrl+Tは未確定中は英数変換、確定後はアプリのショートカットとして働くこと。
8. 文字がない状態のCtrl+CapsLock、Alt+バッククォート、既存の半角/全角のモード切り替えも確認する。
9. かな漢字変換専用モードで、候補を開かずに`ga`→Enter。「が」のまま確定し、「画」などへ変換されないこと。
   `konnichiha`→Enterも「こんにちは」のまま確定すること。
   `ga`→Spaceで「画」などの候補を選んだ場合は、Enterで選択中の候補を確定すること。

単体テストはキーの振り分け、文字種変換、ローマ字変換、UTF-16のカーソル境界、候補ページの端を確認する。
TSFの選択・描画、アプリ固有のショートカット競合は実機確認の対象とする。
